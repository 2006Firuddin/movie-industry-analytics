# 🎬 Movie Industry Data Analytics Project
## 📌 Overview
This project presents an end-to-end data analytics solution designed to analyze historical movie industry performance. 
By examining key metrics such as budget, gross revenue, IMDb ratings, genres, and directors, the goal is to evaluate profitability, return on investment (ROI), and audience trends to derive actionable business insights.
## 🛠️ Tech Stack & Tools
* **Database Management & Querying:** Oracle SQL (Data Extraction & Aggregation)
* **Data Processing & EDA:** Python (Pandas, NumPy)
* **Data Visualization:** Power BI & MS Excel (Dashboards & Interactive Visualizations)
## 📊 Key Insights & Findings
* **Profitability & ROI:** Identified top-performing movie genres and production budgets that yield the highest Return on Investment.
* **Director & Actor Performance:** Analyzed box-office success associated with specific directors and star actors.
* **Audience Engagement vs. Revenue:** Explored the correlation between IMDb user scores, vote counts, and gross revenue.
